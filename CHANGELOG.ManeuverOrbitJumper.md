# Changelog

All notable changes to Maneuver Orbit Jumper are documented here.

## Unreleased

### Added

- Ctrl + add/subtract-orbit jumps by 10 orbits.
- Alt + add/subtract-orbit jumps by 100 orbits.
- Ctrl + Alt + add/subtract-orbit jumps by 1,000 orbits.
- TIME +/- buttons multiply the current slider-selected time step by the same
  Ctrl, Alt, and Ctrl + Alt amounts.
