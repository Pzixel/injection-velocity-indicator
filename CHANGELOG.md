# Changelog

All notable changes to Injection Velocity Indicator are documented here.

## 1.0.0 - 2026-08-20

### Added

- Target-relative speed in the stock celestial-body closest-approach tooltip.
- Recalculation when the displayed separation or maneuver trajectory changes.
- Harmony2 integration without bundling or replacing the shared Harmony DLL.
- Automatic Release ZIP generation and CKAN metadata.
